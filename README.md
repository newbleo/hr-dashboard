# HR 대시보드 (HR Dashboard)

> 채용 지원자 관리와 직원 정보 관리를 한 화면에서 처리하는 웹 기반 HR 대시보드

<br>

## 📌 기획 의도

HR 업무를 경험하면서 느낀 가장 큰 불편함은 **채용 현황과 직원 정보를 각기 다른 문서나 시스템에서 따로 관리해야 한다는 점**이었습니다.

이 프로젝트는 그 문제를 해결하기 위해 기획되었습니다.

- 채용 파이프라인의 각 단계(서류 → 면접 → 최종 → 합격/불합격)를 **한눈에 파악**할 수 있어야 한다
- 지원자 상태를 클릭 한 번으로 **즉시 업데이트**할 수 있어야 한다
- 별도 설치나 서버 없이 **브라우저만으로** 바로 사용할 수 있어야 한다
- 데이터는 **새로고침 후에도 유지**되어야 한다

HR 담당자의 시각에서 실제 업무 흐름을 반영한 도구를 직접 만들어 보고자 했습니다.

<br>

## ✨ 주요 기능

### 채용 지원자 관리
| 기능 | 설명 |
|------|------|
| 단계별 현황 카드 | 서류 / 면접 / 최종 / 합격 / 불합격 인원 수 즉시 확인 |
| 막대 차트 시각화 | 단계별 비율을 애니메이션 막대 차트로 직관적으로 표시 |
| 채용 단계 변경 | 드롭다운 선택 한 번으로 단계 즉시 변경 및 색상 배지 자동 반영 |
| 지원자 추가 | 이름, 지원 직무, 지원일, 초기 단계를 모달 폼으로 입력 |
| 지원자 삭제 | 확인 후 목록에서 즉시 제거 |
| 실시간 검색 | 이름 또는 직무 키워드로 목록 필터링 |

### 직원 정보 관리
| 기능 | 설명 |
|------|------|
| 직원 카드 | 이름, 부서, 직급, 입사일, 근속 기간 자동 계산 표시 |
| 부서별 색상 구분 | 개발 / 디자인 / 마케팅 등 부서마다 고유 컬러 태그 |
| 직원 추가 | 이름, 부서, 직급, 입사일을 모달 폼으로 등록 |
| 직원 삭제 | 확인 후 즉시 제거 |
| 실시간 검색 | 이름 또는 부서명으로 카드 필터링 |

### 공통
- **데이터 영구 저장** — `localStorage` 활용, 새로고침·재방문 후에도 데이터 유지
- **반응형 레이아웃** — 카드 그리드가 화면 너비에 따라 자동 조정

<br>

## 🛠 사용 기술

| 분류 | 내용 |
|------|------|
| 마크업 | HTML5 시맨틱 태그 |
| 스타일 | CSS3 (Flexbox, Grid, CSS 변수, 트랜지션 애니메이션) |
| 스크립트 | Vanilla JavaScript (ES6+) |
| 데이터 저장 | Web Storage API (localStorage) |
| 차트 | 외부 라이브러리 없이 순수 CSS + JS로 구현한 막대 차트 |
| 배포 형태 | 단일 HTML 파일 (별도 서버·빌드 도구 불필요) |

```bash

git clone https://github.com/newbleo/hr-dashboard.git

# hr-dashboard.html 파일을 브라우저로 열기
open hr-dashboard.html   # macOS
start hr-dashboard.html  # Windows
```

## 💡 개발하면서 배운 점

- HR 업무 흐름을 직접 설계하면서 **채용 단계 관리의 시각화가 담당자의 의사결정 속도에 얼마나 중요한지** 체감했습니다.
- 외부 라이브러리 없이 CSS만으로 애니메이션 막대 차트를 구현하며 **브라우저 렌더링 파이프라인(requestAnimationFrame)** 의 동작 방식을 직접 확인했습니다.
- `localStorage`를 통해 클라이언트 사이드 데이터 영속성의 한계(브라우저별 격리, 용량 제한)와 적합한 활용 범위를 이해했습니다.
